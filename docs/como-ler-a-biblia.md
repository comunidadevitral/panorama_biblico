# Como Ler a Bíblia — Implementação

## Visão
Página `/como-ler-a-biblia` com 19 vídeos da série "Como Ler a Bíblia",
organizados em 6 categorias, com filtro e player modal.

## Arquivos
- `src/data/howToReadData.js` — dados dos 19 vídeos + categorias
- `src/pages/HowToReadBible.jsx` — página (grid, filtros, modal, footer)
- `src/App.jsx` — rota `/como-ler-a-biblia`
- `src/components/Header.jsx` — link "Como Ler a Bíblia" no nav

## Funcionalidades
- Filtro por categoria: Todas / Introdução / Narrativas / Poesia & Sabedoria / Discurso & Leis / Novo Testamento
- Cards numerados 01–19 com badge de categoria
- Botão "Assistir Panorama" abre VideoModal com autoplay
- Footer com parceria BibleProject
